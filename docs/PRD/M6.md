## Scope

### 1. Portal — Order Placement Flow
- `/book` page: shipment details form → vehicle selection → pickup/delivery locations → payment mode → submit
- Order created via `orders` table insert (status: `pending`)
- `generate_order_quote()` called on form submit → price displayed to customer
- Payment mode selection (full/partial/to_pay) → `validate_payment_plan()` enforced
- Payment capture stub (Razorpay sandbox or mock) → status advance to `payment_succeeded`

### 2. Portal — Order Tracking
- `/orders/[orderId]` page: status timeline, ETA, driver info (if assigned)
- Real-time status updates via Supabase Realtime subscriptions
- POD upload button → calls `process_document_upload` handler

### 3. Console — Order Monitoring
- `/orders` page: list all orders with status filters
- `/orders/[orderId]` detail page: full order info, state machine timeline, financial breakdown
- Dashboard overview: pending/active/delivered counts, revenue today

### 4. Worker — Full Lifecycle
- Order placement → `enqueue_agent_task('order_management', 'process_new_order')`
- Payment confirmed → auto-assign driver via `match_nearby_drivers()`
- Driver assigned → status advance to `driver_assigned`
- Pickup → in_transit → delivered (manual status updates or driver app stub)
- Delivered → POD upload → settlement trigger
