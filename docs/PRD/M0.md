# Zippy Logistics — Milestone M0: Repository & Toolchain Skeleton

## Objective
Create the working repository structure, monorepo tooling, development environment template, CI/CD skeleton, and deployment contracts required by `PRD-Zippy-Logistics-Control-Plane.md` v2.0.

## Entry Criteria
- GitHub origin repo exists (`zippy-logistics-control-plane`).
- PRD v2 source-of-truth hierarchy acknowledged.
- Target stack confirmed: Next.js Portal, Vite Console, Supabase (PostGIS/pgvector), Python workers, Odoo 18 CE, Langfuse, Honcho, Docker Compose, Vercel.

## Deliverables (this M0)
1. `package.json` with pnpm workspace + Turbo pipeline.
2. `pnpm-workspace.yaml` listing valid packages.
3. Per-app/package stub manifests (`apps/portal`, `apps/console`, `apps/workers`, `packages/shared-types`, `packages/ui`).
4. `infra/docker/docker-compose.yml` (local orchestration: Postgres/PostGIS/pgvector, Redis, Odoo 18, worker placeholder, nginx reverse-proxy skeleton).
5. `.env.example` capturing all PRD v2 environment variables.
6. `.gitignore`, Biome or ESLint/Prettier prettierrc, root `README.md`.
7. GitHub Actions CI skeleton (lint/type-check) and Sonar/Trivy stubs.
8. `MILESTONES.md` master index.

## Exit Criteria / Definition of Done
- [ ] `pnpm install` succeeds at workspace root.
- [ ] `docker compose -f infra/docker/docker-compose.yml config` succeeds.
- [ ] Every app/package has a runnable stub script.
- [ ] CI workflow is green on `main`.
- [ ] Repository tree matches PRD v2 deployable topology (Portal + Console + Workers).

## Human Gates
None. M0 is fully autonomous.

## Rollback
Reset repo to empty origin; restore from `git checkout`.

## Risks
| Risk | Mitigation |
|---|---|
| Path with spaces in workspace (`FRONTEND -OPC`) | All scripts/scripts use quoted absolute paths; cross-checked on Windows PowerShell. |
| pnpm not installed | Document pnpm as prerequisite; fallback to npm 10+ workspaces not yet configured. |
