## Scope

### 1. Document/POD Pipeline
- **order_documents** table — one row per uploaded image, OCR results stored
- **ocr_provider.py** — engine-agnostic interface (`extract_text(image) -> OCRRawResult`)
  - Default: Tesseract (self-hosted, free, already in Docker)
  - Future: vision-LLM swap requires only implementing `OCRExtractor` protocol
- **process_document_upload** handler — OCR extraction → order_documents upsert → auto-transition to `delivered` for POD docs
- Capability: `communication` agent gains `documents` in its write domain

### 2. Notification Agent
- **notification_queue** table — pluggable job queue for multi-channel delivery
- **notification_sender.py** — abstract `NotificationSender` + stub providers (sms, email, push)
- **send_notification()** RPC — enqueue with idempotency key (D-09)
- **process_notification_job** handler — dequeue → render → deliver → log to `notification_log`
- Capability: `communication` agent gains `push` in external (pluggable future provider)

## DB Changes (Migration 12)
- `order_documents` table (PK, order_id FK, doc_type, ocr_raw, ocr_confidence, image_url, created_at)
