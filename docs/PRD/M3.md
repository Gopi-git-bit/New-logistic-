# Zippy Logistics — Milestone M3: Heartbeat Kernel, LoopGuardian & Agent Harness

## Objective
Build the autonomous agent execution core in `apps/workers` (Python 3.12), backed by a DB-side control plane, so every agent runs under the PRD §12–§16 constraints: execution state machine, capability matrix, tool-call cap, budget pause (D-17), and traceable heartbeats.

## Entry Criteria
- M2 complete.

## DB Control Plane (Migration 10)
- `agent_registry` — one row per agent:
  - `agent_name` unique (`customer_service`, `order_management`, `transportation`, `resource_management`, `payment_settlement`, `platform_administration`, `communication`)
  - `status`: `running | paused | blocked`
  - `daily_budget_usd_cents`, `budget_spent_cents`
  - `blocked_reason`, `last_heartbeat_at`
- `agent_tasks` — durable queue with `dedupe_key` idempotency, attempts, dead-letter status.
- RPCs enforcing **D-17 paused-agent skipping at claim time**:
  - `claim_agent_tasks(p_agent_name, p_limit)` → raises `AGENT_PAUSED` / `AGENT_BUDGET_EXHAUSTED`; `FOR UPDATE SKIP LOCKED`
  - `complete_agent_task / fail_agent_task / record_agent_spend / heartbeat_agent`

## Python Core
| Module | Contract |
|---|---|
| `state_machine.py` | PLANNING → EXECUTING → VALIDATING → COMPLETED; failure paths FAILED / BLOCKED / REJECTED. `validate_transition()` raises on illegal hops. |
| `capabilities.py` | 7-agent matrix: read scopes, write scopes, allowed external calls, financial flag, FORBIDDEN list. `enforce_capability()` raises `UnauthorizedCapability`. |
| `loop_guardian.py` | Per-tick tool-call cap from env `MAX_TOOL_CALLS_PER_TICK`; repeated identical call detection → loop flag; malformed/hallucinated payload heuristic checks. Verdicts ALLOW/DENY/BLOCKED with reason codes. |
| `tracing.py` | Langfuse-safe tracer — real HTTP ingestion only when keys exist; no-op span otherwise (offline CI). Trace id = heartbeat id per §16 correlation. |
| `executor.py` | Wires guardian + capabilities + tracer around `run_task()` state flow; persists interventions into `ai_agent_interventions` on BLOCKED. |
| `kernel.py` + CLI | `tick` single-shot & `start` loop; each tick claims tasks, executes ≤ cap, spends budget, writes heartbeat. |
